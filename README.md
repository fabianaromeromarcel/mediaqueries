# Desafío Media Queries

Proyecto desarrollado como práctica de CSS Avanzado utilizando Media Queries, Flexbox y CSS Grid para construir un layout responsive adaptado a dispositivos móviles y escritorio.

## Descripción

La aplicación consiste en una maqueta responsive de una tienda o catálogo de productos que incluye:

- Navbar responsive
- Menú hamburguesa en mobile
- Sidebar de navegación en desktop
- Buscador/filtro de productos
- Grilla de tarjetas responsive
- Footer adaptativo

El proyecto cambia completamente su estructura entre mobile y desktop utilizando Media Queries.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Layout Responsive

### Mobile

- Navbar horizontal
- Menú hamburguesa visible
- Cards en columna
- Layout vertical

### Desktop

- Sidebar lateral
- Menú de navegación visible
- Grid de 4 columnas
- Layout construido con CSS Grid


## Funcionalidades implementadas

- Diseño responsive con breakpoint en 576px
- Uso de display: grid
- Uso de display: flex
- Distribución mediante grid-template-areas
- Cards adaptativas
- Imágenes con object-fit: cover
- Navegación responsive

## Aprendizajes

Durante este proyecto se practicó:

- Construcción de layouts complejos con CSS Grid
- Combinación de Grid y Flexbox
- Organización visual responsive
- Manejo de alturas y overflow
- Uso correcto de Media Queries
- Distribución de contenido en desktop y mobile
